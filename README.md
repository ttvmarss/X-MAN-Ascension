### Quick install
1. Download `KNOWWS_Horror_Pack.mcaddon`
2. Double-click it — Minecraft imports both packs
3. Add **KNOWWS Horror Pack BP** to your world (Settings → Storage → Manage)
4. Enable **Beta APIs**, **Holiday Creator Features**, **Custom Biomes**
5. Re-enter your world

## What's included

- **Verity** — 5-phase AI companion (Nice → Zesty → Weird → Scary → Entity)
- **Voice chat** — Verity Microphone in-game + `verity-voice.html` for real PC mic
- **Guns** — Pistol, Shotgun, Assault Rifle, Sniper, Flamethrower, Plague Cannon
- **Custom ores** — Blood, Silver, Cursed, Nightmare, Plague → weapons & armor
- **Off-hand torch** — Real dynamic lighting in caves
- **4 custom biomes** — Cursed Forest, Blood Marsh, Horror Wastes, Crystal Caverns
- **17+ horror mobs**, 4 armor sets, enhanced cave brightness

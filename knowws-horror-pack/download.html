How to Install

1

Download the KNOWWS_Horror_Pack.mcaddon file using the button above.

2

Open or drag the file into Minecraft Bedrock. Both packs import automatically.

3

Add to your world: Settings → Storage → your world → Manage → Behavior Packs → activate KNOWWS Horror Pack BP.

4

Enable experiments in world settings: Holiday Creator Features, Beta APIs, and Custom Biomes.

5

Meet Verity: A mystery box spawns near you. Break it to release Verity. Type Verity hello in chat to talk!

6

Craft a Glow Torch and put it in your off-hand for real dynamic cave lighting.

⚠️ Custom biomes only generate in new chunks. Horror mobs spawn at night everywhere. For existing worlds, explore new areas to find custom biomes.

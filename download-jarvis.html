JARVIS

Download everything you need to run Jarvis on Windows. No PowerShell commands required.

Step 1 — Install .NET 8 (one time only)

Jarvis does not use special drivers. It needs the free .NET 8 SDK from Microsoft.

Download .NET 8 SDK for Windows
Step 2 — Download the Jarvis launcher to your Desktop

Right-click the button below → Save link as... → save to Desktop as START-JARVIS.bat

Download START-JARVIS.bat
Step 3 — Double-click START-JARVIS.bat

The script downloads the app, builds it, and opens Jarvis automatically.

Optional — Download full project ZIP Download full Jarvis project (ZIP)

After saving START-JARVIS.bat to your Desktop, double-click it. If Windows asks "Do you want to run this file?", click Run.

# X-Man Ascension: Horror Survival — INSTALLATION GUIDE

## 🎮 DRAG & DROP INSTALLATION (Windows/Mac/Mobile)

### **EASIEST METHOD (Recommended):**

1. **Download:** `X-Man-Ascension-Horror-Survival.mcaddon` (complete package)
2. **Locate** your Downloads folder
3. **Open Minecraft Bedrock Edition**
4. **Drag the .mcaddon file** directly into your Minecraft window
5. A popup will appear asking to confirm import
6. **Click "Import"** 
7. **Minecraft restarts with addon enabled**

Done! The horror mod is now active.

### **ALTERNATIVE: Separate Resource & Behavior Packs**

If you prefer separate installation:

1. **Download both files:**
   - `X-Man-Ascension-Behavior-Pack.mcpack` (gameplay systems)
   - `X-Man-Ascension-Resource-Pack.mcpack` (textures/sounds)

2. **Drag both .mcpack files** into your Minecraft window (one at a time)

3. **Click "Import"** for each

Both packs will work together to provide the complete mod experience.

## 📋 DETAILED INSTALLATION STEPS

### **Windows:**
1. Download `X-Man-Ascension-Horror-Survival.mcaddon`
2. Open **Minecraft Bedrock Edition**

## 🐛 TROUBLESHOOTING

### **Packs don't appear after import**
- Make sure **experimental features are enabled**
- Restart Minecraft completely
- Try re-importing the `.mcaddon` file

### **Scripts not working (systems inactive)**
- Check **Script Eval** is enabled in experimental features
- Verify world is in **Creative or Survival with cheats enabled**
- Check console for errors (press T for chat, look for error messages)

### **Items/blocks missing textures**
- This is normal (textures are placeholder)
- Mod is still fully functional
- You can add custom textures (see CUSTOMIZE.md)

### **Performance lag**
- Reduce render distance
- Disable fancy graphics
- Check if too many horror mobs spawned (night time)

### **Can't drag-drop file**
- Use **manual installation** method above
- Ensure file is `.mcaddon` (not `.zip`)
- Try copying file directly to `development_behavior_packs` folder
